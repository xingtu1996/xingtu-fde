# Work 任务卡模板

用于 GitHub Issue。删除示例提示、填具体事实；unknown 是合法值，不能拿默认值充当实测。

## 身份与目标

- task_id / project：
- Chat / Work 名称与职责：
- repository / branch / base_commit：
- 目标使用者、当前问题、完成后的行为：
- issue / draft_pr：

## 已定裁决与授权

| decision_id | proposed/approved/rejected/superseded | 内容与范围 | 批准依据或 unknown |
|---|---|---|---|
| 待填写 | proposed | 待填写 | unknown |

- 必须读取的设计、来源固定版本：
- 本轮允许动作 / 需另行批准的动作：
- 范围之外：

## 执行负责人和并发

- owner / agent_role / 可写文件：
- 已知其他分支、PR、所有权声明：
- 远端核对时点 / 无法观察范围：
- selected_model / reasoning_effort / 核对依据：
- tools / usage_if_available：unknown

## 验收和回退

- Given（输入和前提）：
- When（动作）：
- Then（可观察、可证伪的结果）：
- 必跑检查及预期结果：
- 失败、冲突或权限不足时的处理：
- 回退方式：

## 实际回执（实施后填写）

- status / checked_at：
- Commit / PR / 产物：
- 已执行 / 通过 / 失败 / 未验证：
- 与计划的差异、风险、待决项：
- 下一步与验收责任：

状态及完整协作约定见 [COLLABORATION](../docs/engineering/COLLABORATION.md)。模板复制进 GitHub Issue 后，将该相对链接替换为仓库中的实际文件 URL。
